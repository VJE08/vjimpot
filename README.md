# VJ · Impôt

Site vitrine de Vipithan Jeyaragavan, préparateur de déclarations d'impôts à domicile dans le canton de Neuchâtel.

Site statique (HTML/CSS/JS, aucune dépendance) : ouvrir `index.html` dans un navigateur, ou publier le dossier tel quel (GitHub Pages, Netlify…).

- `index.html` — contenu de la page
- `style.css` — mise en forme
- `script.js` — menu mobile, checklist des documents, formulaire (ouvre un e-mail pré-rempli)
- `assets/` — logo, vidéo de lancement, affiche PDF
